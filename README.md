# 🧮 Calculadora Web Funcional

Una calculadora web moderna, responsiva y completamente funcional desarrollada con HTML, CSS y JavaScript puro.

## ✨ Características

- ✅ **Operaciones Básicas**: Suma, resta, multiplicación y división
- 🔢 **Números Decimales**: Soporte completo para operaciones con decimales
- ⌨️ **Control por Teclado**: 
  - `0-9`: Números
  - `+`, `-`, `*`, `/`: Operadores
  - `Enter` o `=`: Calcular resultado
  - `Backspace`: Borrar último carácter
  - `Escape`: Limpiar todo
- 📱 **Diseño Responsivo**: Funciona perfectamente en móviles, tablets y desktop
- 🎨 **Interfaz Moderna**: Gradiente púrpura, sombras y animaciones suaves
- 🛡️ **Validaciones**: Prevención de división por cero y errores de entrada
- 📚 **Código Documentado**: Funciones con comentarios explicativos

## 🚀 Cómo Usar

### Opción 1: Abrir Localmente
1. Descarga o clona el repositorio
2. Abre `index.html` en tu navegador web
3. ¡Comienza a calcular!

### Opción 2: Usar en Línea
Si deseas alojar la calculadora en línea:
- Sube los tres archivos (`index.html`, `styles.css`, `script.js`) a tu servidor web
- Accede desde cualquier navegador

## 🎯 Funciones Disponibles

| Botón | Función |
|-------|---------|
| **C** | Limpiar todo |
| **←** | Borrar último carácter |
| **+** | Suma |
| **−** | Resta |
| **×** | Multiplicación |
| **/** | División |
| **.** | Decimal |
| **=** | Calcular resultado |
| **0-9** | Números |

- **CSS3**: Diseño responsivo, gradientes, animaciones

## 🔍 Ejemplo de Uso

```
Entrada: 25 + 15 =
Resultado: 40

Entrada: 100 / 4 =
Resultado: 25

Entrada: 7.5 * 2 =
Resultado: 15
```

## ⚠️ Manejo de Errores

- **División por cero**: Muestra "Error: División por 0"
- **Precisión decimal**: Los resultados se redondean a 8 decimales para evitar errores de precisión flotante
